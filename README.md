# Fishing goal task

Goal-setting fishing task (PsychoJS 2024.1.0), demo version.

- **Online:** https://magamoreau28-art.github.io/GS_task_only/goal_task.html
- **Locally:** double-click `run_local.bat` (needs Python), which opens the task in the browser.

At the end, the browser offers to download the data as a CSV file.

This repository only contains the files needed to run the task; it is generated from the development repository by
`tools/export_public_task.py`.
